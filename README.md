# Linux SOC Investigation Lab

## Project Overview

A hands-on educational SOC Analyst Level 1 investigation
using synthetic Linux security logs.

## Incident

SOC-2026-041: Suspicious SSH Activity

A Linux web server recorded repeated failed SSH login attempts,
followed by successful authentication and suspicious account
management activity.

## Objectives

- Investigate SSH authentication events.
- Identify suspicious source IP addresses.
- Analyze post-authentication activity.
- Investigate user and group modifications.
- Correlate firewall events.
- Build an incident timeline.
- Prepare a SOC incident report.

## Technologies

- Linux
- Bash
- SSH
- grep
- awk
- Log Analysis
- Incident Response

## Repository Structure

- logs/ - synthetic security logs
- evidence/ - investigation evidence
- reports/ - incident reports
- scripts/ - analysis scripts
- screenshots/ - project screenshots

## Disclaimer

This project is an educational simulation.
All log data is synthetic and does not represent
a real production security incident.
